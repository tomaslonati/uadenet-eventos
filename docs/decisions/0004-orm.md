# ADR 0004 — Drizzle como ORM

**Contexto:** Necesitamos un ORM/query builder TypeScript para hablar con Postgres (Supabase) desde `apps/api`.

**Opciones consideradas:** Drizzle vs Prisma.

**Decisión:** Drizzle.

**Motivo:** Es la recomendación oficial de Supabase para proyectos edge/serverless: bundle chico (~7 KB), sin paso de generación de cliente, API tipo SQL con full type-safety. Prisma sigue siendo una opción válida (mejor tooling visual con Prisma Studio) pero agrega un paso de `generate` y un runtime más pesado, sin beneficio claro para el tamaño de este proyecto.
